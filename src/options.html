Manga Translate

English over Japanese manga images, made by the vision server and the translation model on your own PC (the same ones MangaVibe's Manga Translate plugin uses).

Your PC

Sites

Where to translate, and which images. The easiest way to add one: open a chapter on the site, click the extension's button and Pick on the page.
Pages: a domain like example.com (every page on it), or a pattern like https://example.com/chapter/*. Images: a CSS selector, e.g. #reader img. Min size: smaller images (icons, ads) are skipped. Next page link: a CSS selector of the link to the next page or chapter (the extension's button → Pick next-page link finds it): near the end of a page, the next one's images are translated in the background.

Keys

Keys for Pause, Hide and Edit (also in the extension's button). They only work on the pages of your sites, and not while you type in a text field. Click a box and press the key (or a combination, like Shift+P); ✕ removes it. A key that does nothing is taken by the browser: pick another. Clashes with one site's own keys? Give that site other keys under Sites → Keys.

Pause translates no more images on this tab (the chapters after it too), e.g. a manga the site already has in English. Press it again to go on.

Saved translations

Each image is translated once and kept in the browser.
